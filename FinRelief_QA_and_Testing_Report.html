5. Critical Bugs Diagnosed & Engineering Resolutions

Defect Identified Underlying Root Cause Engineering Fix Implemented
Passlib & Bcrypt Incompatibility Legacy passlib crashed with modern bcrypt ≥ 4.1 during password hashing. Completely eliminated passlib. Re-engineered password hashing directly using bcrypt.hashpw and bcrypt.checkpw.
Missing DDL Tables on Startup Fresh clones failed on signup with no such table: users. Added automated Base.metadata.create_all(bind=engine) inside the FastAPI startup event.
SQLite Locks in Synced Folders OneDrive/cloud sync locked temporary SQLite WAL files, causing database is locked errors. Configured 30s connection timeout and set PRAGMA journal_mode=DELETE and synchronous=NORMAL.
Relative Database Path Drift Launching backend from different directories spawned isolated, duplicate database files. Implemented dynamic absolute directory resolution in database.py, locking database path to backend root.
Unauthenticated AI Endpoint Exposure POST /api/analyze-debt lacked token protection, risking API quota exhaustion. Secured route behind Depends(get_current_user) and added automatic prompt audit logging to AIHistory.
